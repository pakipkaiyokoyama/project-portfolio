# 制作プロジェクト紹介

学校で取り組んだチーム制作のうち、VRゲームと救命学習ゲームを紹介します。いずれも、企画や技術だけでなく、メンバー間の認識をそろえながら作品を完成させることを意識して取り組みました。

## VRゲーム制作

### 概要

5人のチームで1学期をかけ、VR空間で弓矢を使ってステージを進めるゲームを制作しました。

### 使用技術・ツール

- Unity
- Blender
- GitHub
- SteamVR

### 担当したこと

企画に携わるとともに、チームリーダーとして制作の進行とメンバー間の調整を担当しました。制作開始時に全員と話し、得意分野や作りたいものを整理したうえで役割を決めました。また、GitHubのIssueを使って担当と進捗を見える化しました。

企画段階では、期間内に実現できる範囲と、制作中に発生しそうな技術的課題を整理しました。遅れや技術上の制約が生じた際には、役割や優先順位、企画の方向性を調整し、プロジェクト全体が止まらないように進行しました。

### 学んだこと

チーム制作では、個々の作業だけでなく、作業同士のつながりを把握することが重要だと学びました。また、メンバーの考えを早い段階ですり合わせ、進捗や課題を共有することで、問題が大きくなる前に対応できることを実感しました。

## 救命学習ゲーム制作

### 概要

心肺蘇生やAEDの使用を、ゲームを通して学べる体験型コンテンツをチームで制作しました。Unity上のゲームとArduinoを使った入力デバイスを組み合わせ、身体を動かしながら救命処置の流れを学べるようにしました。

### 使用技術・ツール

- Unity
- Arduino
- GitHub
- 電子回路・配線

### 担当したこと

企画に携わるとともにチームリーダーを務め、主にArduinoを使った入力デバイスの制作と配線を担当しました。また、Unityを含むシステム全体の動作確認や調整にも関わり、デバイスへの入力がゲーム内の動作につながることを確認しながら制作を進めました。

### 学んだこと

ソフトウェアだけでなく、デバイスや配線を含むシステム全体を見て問題を切り分けることの重要性を学びました。また、異なる担当の成果物を組み合わせる際には、仕様や認識を共有し、実際の動作を繰り返し確認する必要があると実感しました。
